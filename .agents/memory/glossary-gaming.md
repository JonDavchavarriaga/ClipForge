# Glosario Gaming y Streams (EN ↔ ES)

Guía viva para mantener consistencia en traducciones de GTA 6, shooters y streams. Edita este archivo cuando aparezcan expresiones recurrentes en tus canales.

## Términos que conviene mantener en inglés (en canal ES)

| Término | Uso natural en español gamer | Evitar |
|---|---|---|
| NPC | "Ese NPC se bugueó" | "personaje no jugable" |
| HUD | "Mira el HUD arriba" | "pantalla de visualización frontal" |
| spawn / respawn | "Hizo spawn justo detrás" | "apareció por generación" |
| clutch | "¡Qué clutch!" | "embrague" |
| nerf / buff | "Le metieron nerf a esa arma" | "debilitaron estadísticamente" |
| lag / ping | "Qué lag tan brutal" | "retraso de red" |
| lobby | "El lobby está lleno" | "vestíbulo" |
| clip / clipear | "¡Clipeen eso!" | "recorten ese fragmento" |
| stream / chat | "Chat, ¿vieron eso?" | "conversación de transmisión" |
| lore | "El lore de Vice City" | "tradición narrativa" |

## Adaptaciones idiomáticas recomendadas (EN → ES)

- "No way!" → "¡No puede ser!" / "¡Ni loco!"
- "Bro, I'm cooked" → "Hermano, estoy acabado" / "Ya perdí"
- "Wait, hold on!" → "¡Espera, aguanta!"
- "That's insane" → "Eso es una locura"
- "He sold the whole game" → "Regaló toda la partida"

## Adaptaciones idiomáticas recomendadas (ES → EN)

- "¡No manches! / ¡Qué locura!" → "No way! / That's insane!"
- "Me regaló la kill" → "He literally gave me that kill"
- "Se bugueó todo" → "The whole game just bugged out"
- "Ojo con esto" → "Watch this" / "Pay attention to this"
- "¿Qué acaba de pasar?" → "Wait, what just happened?"
