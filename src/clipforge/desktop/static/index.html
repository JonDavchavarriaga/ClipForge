Cómo obtener las credenciales
  1. YouTube: console.cloud.google.com → crea un proyecto → habilita "YouTube Data API v3" → Pantalla de consentimiento (tipo Externo, agrégate como usuario de prueba) → Credenciales → ID de cliente OAuth tipo App de escritorio → descarga el JSON y pega su ruta arriba. Cada subida gasta ~1600 de 10 000 unidades diarias (≈6 videos/día).
  2. TikTok: developers.tiktok.com → crea una app → agrega Login Kit (Desktop, con la Redirect URI de arriba) y Content Posting API con el scope video.upload → copia Client key y Client secret. TikTok permite máx. 5 borradores pendientes cada 24 h.
